This is a complete specification guide to build a high-converting, interactive promotional web application for **Gharkilist (घर की लिस्ट)**.

## Quick Overview

- **Project Goal**: Build a promotional landing page and live interactive browser demo for **Gharkilist (घर की लिस्ट)**.
- **Key Features to Showcase**:
  1. **100+ Indian Pantry Catalog** (Bilingual English + Hindi).
  2. **1-Tap WhatsApp Kirana Order Export** (with auto-calculated budget ₹).
  3. **Multi-Inventory Lists** (Pantry, Kirana, Pooja, Festive).
  4. **100% Offline SQLite Privacy** (No account, no tracking).
- **Core Interactive Element**: A live smartphone simulator embedded on the page where users can tap items (+/-), calculate total budget, and simulate sending a formatted Kirana order on WhatsApp!
- **Download Hub**: Release card with `.apk` download link, version details, and QR code for mobile scanning.
